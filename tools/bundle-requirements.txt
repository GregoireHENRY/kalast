# What a release bundle's own interpreter needs installed, beside the kalast
# wheel itself.
#
# Two things, and they are different:
#
#   1. what `import kalast` reaches -- numpy and spiceypy, and nothing else
#      since `kalast.plot` and `kalast.tpm` started deferring their
#      submodules (see `kalast/plot/__init__.py`);
#   2. what the examples the bundle ships actually call. matplotlib for
#      `misc/cbar.py`, `analytical/sinusoidal.py` and
#      `analytical/slab_relaxation.py`; scipy for the last two, one through
#      `kalast.tpm.implicit` and one directly.
#
# **pyarrow is deliberately absent.** It is 120 MB, the largest thing in the
# bundle after the interpreter itself, and the only thing that wants it is
# `kalast.plot.tool`, which no shipped example calls. Reaching for it from a
# bundle now raises ImportError naming pyarrow, which is the honest outcome
# -- `pip install kalast` still brings it.
#
# `tools/bundle_closure.py` re-derives (1). (2) is a judgement about which
# examples ship and has to be read off them.
#
# Nothing has to remember to check this: the release workflow imports kalast
# in the assembled bundle, so a missing entry fails the tag rather than the
# download.
numpy>=2.5
scipy>=1.16
matplotlib>=3.10
spiceypy>=8
